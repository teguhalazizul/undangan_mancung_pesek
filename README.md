# Undangan Mancung Pesek
Edit data di `src/config.js`. Taruh lagu di `public/lagu.mp3` (atau ubah `music` di config).
Nama tamu: `https://domainmu.vercel.app/?to=Nama+Tamu`
```
npm install
npm run dev      # lokal
npm run build    # produksi
```
Deploy: push ke GitHub → Import di Vercel (Framework: Vite, otomatis terdeteksi).
